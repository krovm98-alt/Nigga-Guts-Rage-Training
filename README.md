# Nigga Guts Rage Training

Тренировочный трекер (PWA, Android) в стиле **воронёная сталь и кровь**.

## Возможности

- Push / Pull / Legs с разминкой, рабочими подходами и таймерами отдыха.
- История завершённых тренировок и графики прогресса.
- Консервативные рекомендации по следующей нагрузке по предыдущим трём рабочим подходам.
- Локальные данные в `localStorage`, экспорт и восстановление JSON.
- Service Worker для офлайн-работы после первого посещения.

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

Адрес: `https://krovm98-alt.github.io/Nigga-Guts-Rage-Training/` (станет активен только после успешной публикации).

Открыть в Chrome на Android → меню → Установить приложение / Добавить на главный экран.

**Хранение:** весь журнал остаётся в памяти телефона и не отправляется в GitHub. Сохраняйте резервную копию JSON вне приложения. Не размещайте резервные копии в публичном репозитории.

**Совместимость:** прежние локальные ключи `ddx_` оставлены намеренно для переноса данных v2. Новое приложение на отдельном GitHub Pages домене/пути не получает автоматически историю старой версии; её необходимо экспортировать из предыдущей версии и импортировать в новую.

## Проверки и сохранность

- Локальное хранилище браузера не синхронизируется между телефонами. Делайте резервные копии JSON.
- Сборка `v4-audit`: исправлены проверка импорта, сохранение заметок, обработка ошибок записи и обновление навигационных страниц.
- Для изменения существующего PWA после публикации нужно создать новый кеш с новым именем в sw.js.
