ДАННЫЕ И РЕЗЕРВНАЯ КОПИЯ

Локальное хранение.

Приложение работает офлайн после первой загрузки. Удаление данных сайта или приложения может стереть журнал. Экспортируй резервную копию регулярно и храни её вне приложения.

Импорт объединяет записи по ключам и не удаляет текущую историю. Перед импортом экспортируй текущую копию. Исторические результаты из исходной памятки используются как ориентиры в карточках, а не как выдуманные завершённые сессии.

Для установки PWA размести всю папку на HTTPS-сайте, например GitHub Pages. Открытие index.html как файла не позволяет установить полноценную PWA.
